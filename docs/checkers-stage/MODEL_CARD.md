# 模型卡：2026.09.15-distill1

## 目的与算法

这是搜索教师的监督蒸馏，不是强化学习，不是调用大语言模型下棋。策略头学习完整搜索迭代的候选相对分布；价值头学习静态评价到教师评价的残差。两者在线冻结，不收集玩家棋局上传，也不在浏览器更新权重。

策略：26 输入、32 tanh 隐藏单元、1 logit 输出，共 897 参数。价值：20 输入、24 tanh 隐藏单元、1 输出，共 529 参数。合计 1,426 参数。模型效用/分数不是校准胜率。

策略特征包括当前进营数、目标匹配距离、尾棋进度、走法前后进度/轴线变化、跳跃标志、营地属性、邻居和后续跳跃潜力。六色逻辑坐标已归一化，但本次训练数据只有红蓝双人，运行时禁止将模型直接套用于 3–6 人。

## 数据与划分

固定生成种子 202609150–202609277，128 盘搜索自对弈。共 4,182 个记录局面、83,571 条候选动作。每盘至多 180 手，自对弈遇预算中断时只记录最后完整迭代；自然胜负也记录在数据中，但本次训练目标主要来自教师搜索分数。

教师：最多 3 层，根候选 20，内部宽度 6，每次 18,000 节点，无墙钟时限。它本身是有选择性剪枝的有限搜索，不是最优答案库。

按整盘棋打乱后分组，另外跨集合剔除完全相同的局面+行动者，删除 44 个重复局面。未执行完整棋盘旋转/镜像等价局面去重，因此不将留出结果当成广泛泛化证明。

## 训练与拟合结果

固定训练种子 9152026，CPU AdamW，整盘分组验证选 checkpoint；策略保留第 136 轮，价值保留第 67 轮。PyTorch/NumPy 的实际版本见 `reports/environment.json`。

策略留出交叉熵：2.787247。选中走法处在教师最优分 20 分以内的比例：49.30%。这不是胜率。

价值留出 MSE：0.112659；恒零预测基线：0.216340。价值拟合误差下降不能直接证明棋力提高，因此价值头未上线。

导出的 JS 与 Python logits 已做逐样本数值核对（误差上限 2e-5），夹具在 `tests/model_parity_fixture.json`。

## 棋力与发布决策

验证赛 24 局：9 胜、15 负、0 和。

独立留出赛 64 局：36 胜、28 负、0 和，得分率 56.25%；按整对换色比赛重采样，95% 区间 [50.00%, 64.06%]。下界没有严格大于 50%，所以 **策略、价值默认都关闭**。此时没有进入额外墙钟预算模型晋级赛；不能拿 36 胜 28 负就宣传显著提升。

本包完整公开留出集、种子与棋谱；后续开发必须建立新的留出测试，避免对已公开测例过拟合。

## 已知限制

模型只模仿有限教师、动作特征不能完整表达所有跳板拓扑、根候选原本也有剪枝、未使用人类数据、未做大规模强化学习、未测人类等级分、未训练多人价值向量。默认关闭是发布门槛的实际结果，不是没有提供训练权重。
