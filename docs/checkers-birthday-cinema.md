# 生日庆祝流程

仅生日主题启用：9 月 19 日自动开启，或使用 `play.html?birthday=1`；`birthday=0` 保留普通游戏。可用 `name` 指定祝福对象，默认“玫玫”。

- 开场：点击“拉开帷幕”后，两侧幕布约 3.8 秒缓缓展开并露出祝福棋盘，柔光与棋盘显现同步放慢；支持“跳过开场”和 Escape。开场不播放声音，棋盘及本地 AI 暂停操作。
- 联机房间先展示等待页，不提前展示主题棋盘和开场。两位真人到齐后，由房主点击“开始对局”，双方自动播放开幕，无需再分别点击拉幕；服务端收到双方本轮开幕完成确认后才允许走棋。普通模式直接确认，减少动态效果模式立即揭幕。对局中重连不重播。
- 联机阵营固定为房主蓝、客人红，各自视角保持己方在下。房主开始时由服务器为红蓝双方各掷一颗六面骰，大点先手，平点自动重掷；结果随房间状态同步，重连不重掷、下一局重新掷骰。带电脑时先手仍从两名真人中决定，随后按原座位顺序轮转。带一个电脑的三人房采用红、绿、蓝三个营地，保证真人红蓝对家；本地多人布局及红方先行规则不变。房主主动离房后，接任者切换蓝方并等待新客人；短暂断线不转让房主。
- 结局：显示五根蜡烛的蛋糕；“许好愿了，吹蜡烛”熄灭烛火并播放浏览器合成的 Happy Birthday 音乐盒旋律。无需麦克风或外部录音。
- 静音时先吹灭蜡烛，不强制播放；点击“播放生日歌”可主动开启声音。支持停止、重播，离开页面、切换后台或重开都会停播。
- 保留获胜阵营作为次要文字及“再来一局”。重复的联机结局消息不会反复点蜡烛、启动音乐；已结束存档可直接进入蛋糕流程。
- 遵循减少动态效果偏好：立即揭幕、不闪烁烛火、不撒花；文字祝福、蛋糕及音乐按钮仍可使用。

视觉细化：帷幕加入顶部垂幔、展开时的柔光和缓动；蛋糕为独立内嵌 SVG，包含奶油滴边、金边、糖珠和莓果。五根蜡烛有独立烛芯、内外焰与柔光；点击后约 0.85 秒内依次弯曲熄灭并散出烟雾，旋律在约 0.9 秒后接入。减少动态效果时立即熄灭。重复点击、重开和关闭弹窗均有状态保护与定时器清理。

表现层通过 `checkers:winner`、`checkers:winner-close`、`checkers:newgame` 和 `checkers:opening-end` 事件与棋局交互，不再包装 `window.showWinner`。规则和 AI 搜索算法未修改。

验证：`npm run test:all`；真实 Chrome UI 测试 `npm run test:checkers:birthday-ui`（需 Playwright，可用 `PLAYWRIGHT_MODULE` 指定现有 Playwright 模块路径）。UI 测试自动启动本地服务、使用隔离浏览器，并在结束后关闭两者；截图默认输出临时目录，可通过 `BIRTHDAY_SCREENSHOTS` 指定输出目录。

发布前运行 `npm run version:assets`，随代码发布生日 JS/CSS 并重启 Node 服务。服务器按文件路径缓存静态内容，仅换 URL 哈希不会清除服务器旧内容。
